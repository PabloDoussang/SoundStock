SOUNDSTOCK-MAIN: FAKER Y UBICACIÓN DE LOS ARCHIVOS
===================================================

ABRIR LA TERMINAL
-----------------
Abre la carpeta SoundStock-main en VS Code y usa una terminal CMD.
Dentro de SoundStock-main deben verse README.md y la carpeta SoundStock.
Si ves otra SoundStock-main adentro, abriste la carpeta exterior de extracción.
Escribe:

    venv\Scripts\activate.bat
    cd SoundStock

Los comandos siguientes se ejecutan desde la carpeta que contiene manage.py.
Si aparece "can't open file ...SoundStock-main\manage.py", falta el paso
"cd SoundStock". El comando de productos se llama seed_productos (plural).
Los comandos seed_* guardan registros en db.sqlite3; no crean archivos nuevos.
Si abriste el proyecto desde el ZIP en otro equipo, primero crea el entorno
con "python -m venv venv", actívalo y ejecuta "pip install -r requirements.txt"
desde la carpeta interna SoundStock. Después ejecuta "python manage.py migrate".

CARGAR PRODUCTOS FICTICIOS
--------------------------
Elige el total que quieres guardar en tu base local:

    python manage.py seed_productos --cantidad 100
    python manage.py seed_productos --cantidad 1000
    python manage.py seed_productos --cantidad 100000 --lote 5000
    python manage.py seed_productos --cantidad 1000000 --lote 5000

Puedes usar cualquier número de 1 a 1.000.000. Si ejecutas primero 100 y
después 1.000, quedan 1.000 productos DEMO, no 1.100: el comando reconoce
los códigos existentes. Para sumar un grupo distinto, cambia el prefijo:

    python manage.py seed_productos --cantidad 500 --prefijo OTRO

Así tendrás los productos DEMO más 500 productos OTRO.

USUARIOS Y MOVIMIENTOS FICTICIOS
--------------------------------
    python manage.py seed_usuarios --cantidad 20
    python manage.py seed_movimientos --cantidad 80 --tipo entrada
    python manage.py seed_movimientos --cantidad 40 --tipo salida

Antes de cargar 80 entradas, debes tener al menos 80 productos DEMO.
Las salidas se ejecutan después de las entradas y nunca descuentan más del
stock disponible. Si no escribes --tipo, el comando crea entradas. Los
productos sin movimientos quedan agotados. Para ver variedad de estados,
carga movimientos para parte de ellos (por ejemplo, 80 de 100 productos).
Si tus productos usan --prefijo OTRO, añade --prefijo OTRO al comando de
movimientos. Repetir cualquiera de estos comandos no duplica sus registros.
Los usuarios ficticios quedan desactivados; no reemplazan al administrador.

COMPROBAR LOS DATOS
-------------------
    python manage.py verificar_bd --salida archivos_de_apoyo\VERIFICACION_BD.json

Para verlos en la página, ejecuta "python manage.py runserver 127.0.0.1:8000"
y abre http://127.0.0.1:8000/admin/.

PRUEBA DE LAS CUATRO CANTIDADES DE LA PAUTA
------------------------------------------
    python manage.py evaluar_cargas

Prueba 100, 1.000, 100.000 y 1.000.000 de productos y guarda el resultado
en archivos_de_apoyo/RESULTADOS_CARGAS.json. Usa una base temporal: no añade
el millón a la base local que ves en Admin. Para llenarla, usa seed_productos.
